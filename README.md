## How it works

`main.ts` (Node 22+, stdlib only, no dependencies, no network) writes exactly
that one line to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` or `OUTPUT_DIR` (fallback `/output`). It refuses to write
if the line falls outside the competition's 1–200 character gate.

```sh
node main.ts
```
